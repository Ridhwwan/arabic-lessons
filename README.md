# Arabic lessons

Daily five-minute spoken Fuṣḥā lessons, shown at https://www.ridhwansalaudeen.com/arabic-classes

- `index.json` lists every lesson (`n`, `date`, `title`, `titleAr`).
- `lessons/0001.json` holds one full lesson: sections of lines, each with voweled Arabic (`ar`), English (`en`) and an optional speaker (`who`).

A new lesson is added here every morning at 6 AM Lagos time. The site reads these files when a visitor opens the page, so adding a lesson doesn't redeploy the site.
